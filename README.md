# THE WORLD IN ONE DAY — 21 November 2026

A code-drawn 1024x1024 broadsheet front page chronicling 35 verified global news stories across 7 regions for Saturday 21 November 2026, built for the `news-image-20261121` make.fun bounty.

## Overview

- **Layout:** Broadsheet front page (1024x1024 PNG) rendered entirely via Python 3 + PIL with zero external image dependencies.
- **Coverage:** 35 verified stories across Europe, Asia, Middle East, Africa, Americas, Oceania, and Global sectors.
- **Verification:** Strict date-check filtering and multi-source corroboration against reports up to 04:00 UTC, 22 November 2026.
- **Generator:** Deterministic PIL drawing script (`ni21-harness/draw.py`) producing identical outputs across runs.

- `entry.png` - Generated broadsheet front page image (1024x1024, RGB PNG).
